# 냉동공조기계 이상감지시스템 구축 기획서

## 1. 프로젝트 목적
전국 여러 사업장에 있는 냉장/냉동시설(혹은 냉장/냉동고)의 온도를 주기적으로 전송하고, 각 사업장에서 설정한 임계치 이상으로 온도가 상승할 시 이상을 감지하여 관리자에게 알림을 전송하는 시스템입니다.

> **💡 이번 단계 개발 범위 제한 (Scope)**
> * 본 개발 건에서는 **데이터 수집(DB 저장) 및 관제 대시보드 구축**까지만 진행합니다.
> * 휴대폰 관리자 알림(SMS/푸시 등) 기능은 추후 고도화 단계에서 구현하기로 합니다.

---

## 2. 시스템 아키텍처 및 핵심 기능

### 📌 데이터 수집 및 전송 (하드웨어 단)
* **단말 디바이스:** Raspberry Pi Pico W (`RP2040`)
* **개발 환경:** C++ 및 FreeRTOS 활용
* **데이터 수집:** Pico W에 연결된 온도센서로부터 주기적으로 온도 값 측정
* **데이터 전송:** lTE 모뎀을 이용한 소켓 통신(TCP/IP)을 통해 수집된 데이터를 백엔드/DB로 전송

### 📌 백엔드 및 웹 서버
* **메인 데이터베이스:** Supabase (PostgreSQL 기반)
* **웹 서버 운영:** 별도 구축된 Linux(Ubuntu) 서버 환경
* **웹 프레임워크:** Python Flask 기반 API 및 웹페이지 제작
* **주요 기능:** 사용자 인증(로그인/회원가입), 게시판 CRUD 기능 처리

### 📌 관제 대시보드 애플리케이션
* **데스크톱 앱 패키징:** Python `pywebview` 라이브러리를 활용한 독립 실행형 대시보드 구축
* **인증 아키텍처:** 세션 또는 토큰 기반 로그인을 완료해야만 대시보드 메인 화면 접근 가능
* **프로세스 관리:** 화면 멈춤 방지 및 안정적인 데이터 갱신을 위해 멀티프로세스(Multiprocessing) 활용
* **통신 구조:** Linux 웹 서버와 TCP/IP 통신을 통해 실시간/주기적 정보 수신

## 3. 대시보드 UI/UX 요구사항 Layout

* **상단/메인 영역:**
  * 전국 전체 기기의 평균 온도 모니터링 수치
  * 현재 임계 온도를 초과한 '온도 이상 발생 기기' 목록 및 알림 표시
* **우측 사이드바 영역 (검토 중):**
  * DB(Supabase)에 적재된 로그 및 이력을 기반으로 사용자 질문에 답변하는 간단한 **챗봇 UI** (구현 여부 미정)
* **하단 영역:**
  * 시스템 및 통신 상태를 실시간으로 모니터링할 수 있는 **Logging 창** (최신 5~10줄 고정 노출)
* **네비게이션 메뉴:**
  * 관제 화면과 분리된 별도의 **게시판 메뉴**를 구성하여 운영 이력 공유 및 공지사항 활용
